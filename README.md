# 🌀 陀螺實驗室

給 6–7 歲孩子和大人一起看的戰鬥陀螺（Beyblade X）入門網站。

- 網址：https://stitchfi.github.io/beyblade-lab/
- 純靜態網頁，不需要登入或計分。

## 頁面

| 檔案 | 內容 |
|---|---|
| `index.html` | 首頁目錄 |
| `parts.html` | 零件區：刃、齒輪、軸心，看懂陀螺名字 |
| `types.html` | 陀螺類型：四種類型和相剋 |
| `assemble.html` | 組裝區：組裝步驟、發射器、零件搭配小遊戲 |
| `launch.html` | 發射與轉法：四種軸心和發射方式的動畫 |
| `battle.html` | 戰鬥規則區：4 種終結動畫、比賽流程、計分板 |
| `worksheet.html` | 可列印的實驗學習單 |
| `shop.html` | 購物清單（只列型號） |

共用：`style.css`、`site.js`（頁首導覽、上下頁、頁尾，新增頁面要加進 `PAGES`）、`demo.js`（俯視對戰盤的動畫示範，情境寫在 `DEMOS`）。

資料參考 Takara Tomy《Beyblade X Start Dash Guide》。動畫是示意，不是真實物理數據。

BEYBLADE® 是 Takara Tomy 的商標，本站為個人製作的教學網站，與 Takara Tomy 無關。
